# デッキプロジェクト

このディレクトリは Beamer サブセット形式のスライドデッキ(`*.slide.tex`)のプロジェクト。
スライドの作成・編集・書き出しは beamer-deck スキル(`.claude/skills/beamer-deck/`、
`.agents/skills/beamer-deck/`)の手順に従う。

- スライドの正本は .tex。「GUI で操作」「プレビューで動かせるように」は VS Code 拡張の
  プレビューで編集できる状態を指し、pptx に置き換えない
- 通常の作成・編集は .tex の作成・更新と必要な検証・報告で完了する。
  HTML・PDF はその形式の出力を明示的に依頼された場合だけ、依頼された形式だけを
  書き出す。編集後の仕上げとして両方を自動生成しない。
  `deck check` / `deck snapshot` は検証であり、成果物の書き出しとは別に扱う
- 通常の作成・編集は、依頼の意図と内容に応じて通常フローか canvas を選ぶ。新規作成や
  依頼で触る既存フレームを、それだけを理由に変換せず、既存の適切な構造は保つ
- 「GUI で操作」「プレビューで動かせるように」と自由配置を明示された場合は、依頼で指定された
  対象要素のうち移せるものだけを `deckcanvas` の `decktext` / `deckimage` へ移す。移せない指定対象要素と、
  同じフレームを含む対象外の全要素はそのまま残し、理由を報告する
- `deckimage` は PNG / JPEG / PDF のみ対応する。SVG は利用可能な手段で PNG / PDF に
  実際に変換してから置き、変換手段がなければ未対応として報告する。
  素材の変換はデッキ全体の HTML・PDF 書き出しとは別に扱う
- キャンバスを書いた・触ったら `deck check` まで実行し、書いた・触ったフレームに lint の
  L011・L012・L014・L018・L019 か check の `canvas-overflow` が残っていたら
  完了にしないで、残ったものを報告する
- PDF 出力を明示的に依頼された場合は
  `deck export <file> --format pdf -o <pdf>`(どちらも絶対パス)で書き出し、
  PDF のパスを報告する
- HTML 出力を明示的に依頼された場合は
  `deck export <file> --format html -o <directory>`(どちらも絶対パス)で書き出し、
  出力先を報告する
- pptx / PowerPoint は、ユーザーが形式を明示したときだけ、かつ利用可能な外部ツールまたはスキルで実際に作成できる
  場合だけ .tex を残したまま別に作る。利用手段がなければ未対応として報告し、作成を約束しない
